  \begin{Large}
    \textbf{Resumen}\\
  \end{Large}
  \masterRule
\end{flushleft}

\vspace*{1cm}

Este trabajo presenta el desarrollo de una infraestructura \textit{hardware} para la integración de aceleradores de propósito específico en plataformas \textit{RISC-V} utilizando la abstracción de tareas de FreeRTOS. La propuesta busca ofrecer al programador un modelo uniforme y eficiente, donde cada acelerador se trate como una tarea \textit{hardware} que se ejecuta concurrentemente con las tareas \textit{software} tradicionales. Para ello, se implementa una arquitectura basada en colas \textit{hardware}, que facilitan la comunicación y sincronización entre el microcontrolador y los aceleradores, ocultando la complejidad de bajo nivel. La infraestructura se despliega sobre una extensión de la plataforma \textit{X-HEEP}, denominada \textit{GR-HEEP}, permitiendo validar su funcionalidad y explorar un marco de integración más generalizado. El enfoque presentado facilita la programación de sistemas embebidos heterogéneos, optimizando el uso de recursos especializados y promoviendo la portabilidad y accesibilidad del desarrollo en aplicaciones críticas de tiempo real.
